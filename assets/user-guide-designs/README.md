# Atlas Camera user-guide design concepts

Three visual directions for a future Atlas Camera user guide. Each concept uses
the existing `assets/atlas_camera_icon.png` as its brand reference and shows a
cover plus representative interior pages.

## 01 — Cinematic Control

**File:** `atlas-user-guide-01-cinematic-control.png`

A premium dark VFX manual. It uses an editorial grid, condensed display type,
amber framing rules, camera diagrams, crop marks, and restrained architectural
imagery. This is the strongest direction for a polished product manual or
filmmaking audience.

**Generation brief:** Create an A4 cover, camera-recovery chapter opener, and
technical settings page. Use near-black, Atlas amber `#eaa03a`, bone white, and
graphite. Preserve the supplied Atlas mark. Prominent copy: “ATLAS CAMERA”,
“USER GUIDE”, “CINEMATIC CONTROL”, “01 — CAMERA RECOVERY”,
“SOLVE → RELIEF → REPAIR → EXPORT”, and “OPERATOR NOTES”.

## 02 — The Survey Field Guide

**File:** `atlas-user-guide-02-survey-field-guide.png`

A bright, approachable architectural field manual. It combines warm paper,
survey notation, contour lines, numbered callouts, navigation tabs, and
measurement diagrams. This is the clearest direction for onboarding and
print-friendly documentation.

**Generation brief:** Create an A4 cover, relief-and-scale chapter opener, and
annotated workflow page. Use warm ivory, deep navy, Atlas amber, muted sage, and
pale blueprint blue. Preserve the supplied Atlas mark. Prominent copy:
“ATLAS CAMERA”, “USER GUIDE”, “THE SURVEY FIELD GUIDE”,
“02 — RELIEF & SCALE”, “RECOVER”, “MEASURE”, “PROJECT”, “VERIFY”, and
“FIELD NOTES”.

## 03 — The Operator Graph

**File:** `atlas-user-guide-03-operator-graph.png`

A graph-native procedural handbook. It turns Atlas workflow logic into an
editorial system using connected cards, layer chips, mask thumbnails, repair
colors, and troubleshooting gates. This is the best match for ComfyUI users and
future MCP/agentic workflow documentation.

**Generation brief:** Create an A4 cover, hole-repair chapter page, and
troubleshooting workflow page. Use graphite, warm grey, Atlas amber, muted cyan,
restrained magenta, and white. Preserve the supplied Atlas mark. Prominent copy:
“ATLAS CAMERA”, “USER GUIDE”, “THE OPERATOR GRAPH”, “03 — HOLE REPAIR”,
“SELECT”, “PATCH”, “SMOOTH”, “VERIFY”, and “AGENT NOTES”.

## Generation mode

Generated as three independent raster publication mockups with the built-in
image-generation tool. The original generated outputs remain in the Codex
generation cache; these project copies are the working assets.
